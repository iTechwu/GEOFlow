### MCP 鉴权 / 幂等 / 审计（0821 后续落实）

- 新增可选只读令牌 `GEOFLOW_MCP_READ_TOKEN`：只允许 catalog / tasks.list / tasks.get，写工具返回 `isError: true`；`GEOFLOW_MCP_TOKEN` 保持全量读写。中间件写入 `McpAuthContext`（作用域 + 令牌 SHA-256 指纹）。
- 三个写工具接受可选 `idempotency_key`，复用 `api_idempotency_keys` 表（路由键 `mcp:tools.call:<tool>`），实现重试命中缓存、同键不同参数冲突、进行中/过期预留等语义。
- 新增 `mcp_audit_logs` 表 + `McpAuditLogger`，写工具落审计（令牌指纹、作用域、工具、task_id、幂等键、结果、IP、脱敏参数）。
- 扩展 `McpEndpointTest` 覆盖：默认关闭、无 Token 401、初始化/tools/list、只读令牌读放行与写拒绝、写令牌写放行、幂等重放、审计落库。
- 新增 `deploy-scripts/check-compose-boundaries.sh` + `.github/workflows/ci.yml` + Makefile 目标，CI 拦截 PostgreSQL/Redis/RabbitMQ 服务重新进入应用编排，并跑 PHP 语法检查与 PHPUnit。

任务所有权策略：MCP 是无状态部署令牌，不绑定 SSO 管理员，因此以「写/读作用域 + 审计」作为授权边界（REST API 仍走 `sso_owner_admin_id` + `ensureTaskOwnedBy`）。如需按租户细分 MCP 任务可见范围，需与 models/SSO 侧对齐后再单独设计。

## 本地验证限制

当前工作区没有 `php` CLI，无法运行 PHPUnit、`php artisan route:list` 或 Laravel 运行时冒烟。生产验证必须在 CI 镜像内执行：

```bash
php -l app/Http/Controllers/McpController.php
php -l app/Http/Middleware/AuthenticateMcpToken.php
php -l app/Http/McpAuthContext.php
php -l app/Services/Mcp/McpIdempotencyService.php
php -l app/Services/Mcp/McpToolException.php
php -l app/Support/McpAuditLogger.php
php -l app/Models/McpAuditLog.php
php artisan route:list --path=mcp
php artisan migrate --pretend
php artisan test --filter=Mcp
```

### models /internal HMAC 复审结论

- 已实现 `ModelsInternalAuth` HMAC 客户端，并对齐 models 侧 `internal-auth.guard.ts` 的 canonical 串（硬编码向量单测）。
- 澄清：models 的 `/internal/*`（`InternalAuthGuard`）只服务管理端点（catalog/pricing/billing/provider-key/usage 等），**不服务** chat/embeddings；chat/embeddings 走公共 `/v1`（`proxy-api`）+ `MODELS_API_KEY`。因此 HMAC 客户端定位为「管理端点服务间鉴权（预留）」，不接入 chat/embedding 运行时 Provider，避免把请求打到不存在的 `/internal/v1/chat/completions`。
