## 2. 浏览器测试方法

用户指定的 Chrome DevTools MCP 在本会话中不可用，因此使用真实安装的 Google Chrome，通过 Playwright/CDP 采集页面 DOM、HTTP 状态、console、失败请求、布局溢出和交互结果。测试脚本位于临时验收目录：

- `geoflow-browser-audit.mjs`：隔离环境页面矩阵、桌面/移动视口和管理端交互。
- `geoflow-lead-e2e.mjs`：创建表单、公开提交、管理端线索列表和详情闭环。
- `geoflow-prod-public-audit.mjs`：生产 Docker 匿名页面和资源加载审计。

隔离环境使用独立 SQLite、独立 PHP 服务和临时 fake OIDC，仅用于浏览器回归，不连接生产数据库或生产 SSO。

## 6. 发现、修复与回归

| 发现 | 根因 | 修复 | 回归结果 |
| --- | --- | --- | --- |
| 生产 Web/App 初始 500、队列重启 | `.env.prod` 的 `REDIS_URL` 覆盖外部 Redis 主机 | 移除覆盖项，统一使用 `dofe-redis`，运行时注入配置 | Redis PING、Web/App 健康检查通过 |
| PHP-FPM 无法读取源码 trait | 宿主机文件权限为 `0600` 并被复制进镜像 | Dockerfile 统一应用源码目录 `755`、文件 `644` | 生产 trait 可读，应用健康检查通过 |
| 公共首页缺少明确 H1、移动菜单无名称 | 默认主题只渲染侧栏标题，按钮没有可访问名称 | 增加首页 H1、调整侧栏层级、补充菜单 `aria-label` | 隔离/生产首页 H1=1，未命名操作=0 |
| 管理端无障碍改动导致 pt_BR 覆盖测试失败 | 新增 4 个翻译键未同步到葡萄牙语 | 补充 `header.account_menu`、`header.mobile_menu`、`articles.bulk.select_all`、`articles.bulk.select_article` | `AdminPtBrLocaleCoverageTest` 2/2 通过 |
| 外部端口部署时资源 URL 丢失 `:18080` | `X-Forwarded-Port` 回退到 Nginx 容器内部端口 80 | 从外部 `Host` 提取端口并透传 `X-Forwarded-Host/Port` | 生产资源 URL 带外部端口，浏览器失败请求=0 |
