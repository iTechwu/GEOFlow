## 当前调用边界

| 能力 | GEOFlow 配置 | models 路径 | 鉴权 |
| --- | --- | --- | --- |
| Chat | `MODELS_BASE_URL`、`MODELS_API_KEY` | `/v1/chat/completions` | 公共 API key |
| Embedding | `MODELS_BASE_URL`、`MODELS_API_KEY` | `/v1/embeddings` | 公共 API key |
| 模型目录管理 | `MODELS_INTERNAL_BASE_URL`、`MODELS_INTERNAL_API_SECRET` | `/internal/models` | 服务间 HMAC + `x-service-name` |

不要将 `/internal/*` 作为 Chat 或 Embedding Provider 地址；models 当前内部代理只覆盖管理面和特定内部能力。
